# HireLoop prototype

A self-contained, single-file HTML prototype (`index.html`), served with GitHub Pages.

**Live:** https://kushajjee-tech.github.io/hireloop-prototype/

## Run locally

Open `index.html` in a browser. You don't need a build step or any dependencies.

## Deploy

Every push to `main` redeploys the site through GitHub Pages (branch `main`, root folder).
